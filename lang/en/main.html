      Basics

      What is the ESP32?

      The ESP32 is a microcontroller made by Espressif with WiFi and Bluetooth built into one chip. The most common board is the 30-pin ESP32 DevKit V1, the one you rotated above. The large metal can at one end is the ESP32-WROOM-32 module: it holds the chip, 4 MB of flash memory, and the zig-zag antenna at the tip.

      You program it in the Arduino IDE with the same functions as an Arduino: pinMode, digitalWrite, analogRead, Serial.println. The differences are the voltage, the number of features, and a few pin rules.

      What is it used for?

      Smart home

      Control lights from your phone

      The ESP32 is powerful enough to run its own web server. Open its IP address in your phone browser, tap a button, and the relay switches on.

      Monitoring

      Monitor room temperature

      Read temperature, humidity, or soil moisture and show it on your phone. The basis of smart gardens and aquarium monitors.

      Security

      Detect motion

      A PIR sensor detects moving body heat. Turn on a light, sound an alarm, or send a notification.

      Robotics

      Robots and robot arms

      Control motor speed with PWM, move a servo to a set angle, and avoid obstacles with a distance sensor.

      Bluetooth

      Remotes and wearables

      Low-power BLE connects the ESP32 to a phone app, for example a remote, a wristband, or a heart-rate sensor.

      Battery

      Devices left out in the field

      Deep sleep mode cuts the ESP32 chip down to microamps, then wakes it every few minutes to send data.

      Key rules when moving from Arduino

      • 3.3VESP32 logic is 3.3 V. Never feed 5 V straight into a GPIO. Signals from 5 V sensors need a voltage divider or a level shifter.
      • ADC2While WiFi is on, ADC2 pins (GPIO 0, 2, 4, 12–15, 25–27) cannot analogRead. Use ADC1: GPIO 32–39.
      • 34–39GPIO 34, 35, 36 (VP), and 39 (VN) are input-only and have no internal pull-up.
      • 0-4095analogRead returns 0–4095 (12-bit), not 0–1023. The Serial Monitor is usually set to 115200 baud.
      • BOOTStrapping pins (GPIO 0, 2, 5, 12, 15) set the boot mode at power-up. Do not attach loads that pull them to the wrong level.
      • 6–11GPIO 6–11 are used by the flash memory and are not broken out on the 30-pin board. If another board exposes them, leave them alone.
      • 20mAKeep each pin under about 20 mA. Motors, relays, and lamps always go through a driver module, never straight from a pin.
      • GNDWhen you use a separate power supply (motor battery, adapter), connect its GND to the ESP32 GND.

      How the ESP32 talks over WiFi

      The 2.4 GHz WiFi radio is inside the chip, and the antenna is the zig-zag trace at the end of the module. There are two modes you will use most.

        
          
        The ESP32 can only join 2.4 GHz WiFi. If your router is dual-band, make sure its 2.4 GHz network is enabled.
        
        
        
        
        
          
        The ADC turns voltage into a number
        
          
        The potentiometer divides the 3.3 V supply. The 12-bit ADC measures the voltage on pin D34 and turns it into a number from 0 to 4095. The twelve blocks above are the 12 bits of that number.
        
          
        
          
          
        
            
        1.65 VPin voltage
        
            
        2048analogRead(34)
        
          
        
          
        100000000000In binary (12 bits)
        
          
        // raw value 0–4095
int value = analogRead(34);
// approximate voltage
float volts = value * 3.3 / 4095.0;
// more accurate, in millivolts
int mv = analogReadMilliVolts(34);
        
          
        The ESP32 ADC is less linear near 0 V and 3.3 V. For voltages, analogReadMilliVolts() uses the factory calibration, so it is more accurate.
        
        
        
        
        
          
        PWM: faking analog
        
          
        Most ESP32 pins can only be HIGH (3.3 V) or LOW (0 V). PWM switches the pin on and off very quickly. The share of time spent HIGH is the duty cycle, and the average feels like a lower voltage.
        
          
        
          
          
        
            
        77ledcWrite (0–255)
        
            
        0.99 VAverage voltage
        
          
        
          
        // pin 18, 5 kHz, 8-bit resolution
ledcAttach(18, 5000, 8);
// 77 out of 255 = 30% duty
ledcWrite(18, 77);
        
          
        Turn slow mode off. At 5 kHz your eye cannot see the blinking, so the LED looks dim and steady. The same trick controls motor speed.

            Get started on your computer
            
          
            Set up the Arduino IDE for ESP32
            
        
            
        
              
          
            1. Install Arduino IDE 2
              Download it from arduino.cc. If you already have it, skip to the next step.
              2. 
          
            2. Add the ESP32 board URL
              File → Preferences → Additional boards manager URLs, paste this address:
              
            
              https://espressif.github.io/arduino-esp32/package_esp32_index.json
              3. 
          
            3. Install the board package
              Tools → Board → Boards Manager, search for esp32, and install esp32 by Espressif Systems (version 3.x).
              4. 
          
            4. Plug in the board
              Use a USB data cable, not a charge-only cable. If no port shows up, install the CP210x or CH340 driver to match the USB chip on your board.
              5. 
          
            5. Choose the board and port
              Tools → Board → ESP32 Dev Module, then Tools → Port. If uploads keep failing, lower Upload Speed to 115200.
              6. 
          
            6. Upload
              If Connecting..... keeps going, hold the BOOT button on the board until the upload percentage starts moving.
