      Kenalan

      Apa itu ESP32?

      ESP32 adalah mikrokontroler buatan Espressif dengan WiFi dan Bluetooth di dalam satu chip. Board yang paling banyak dijual adalah ESP32 DevKit V1 30 pin, yang kamu putar di atas. Kotak logam besar di ujungnya adalah modul ESP32-WROOM-32: di dalamnya ada chip, memori flash 4 MB, dan antena zig-zag di ujung modul.

      Kamu memprogramnya di Arduino IDE dengan fungsi yang sama seperti Arduino: pinMode, digitalWrite, analogRead, Serial.println. Perbedaannya ada di tegangan, jumlah fitur, dan beberapa aturan pin.

      Dipakai untuk apa?

      Smart home

      Kontrol lampu dari HP

      ESP32 cukup kuat menjalankan web server sendiri. Buka alamat IP-nya di browser HP, tekan tombol, relay menyala.

      Monitoring

      Pantau suhu ruangan

      Baca suhu, kelembapan, atau kelembapan tanah, lalu tampilkan di HP. Dasar dari kebun pintar dan monitor akuarium.

      Keamanan

      Deteksi gerakan

      Sensor PIR mendeteksi panas tubuh yang bergerak. Nyalakan lampu, bunyikan alarm, atau kirim notifikasi.

      Robotika

      Robot dan lengan mekanik

      Atur kecepatan motor dengan PWM, gerakkan servo ke sudut tertentu, hindari halangan dengan sensor jarak.

      Bluetooth

      Remote dan wearable

      BLE hemat daya untuk menghubungkan ESP32 ke aplikasi HP, misalnya remote, gelang, atau sensor detak jantung.

      Baterai

      Alat yang ditinggal di lapangan

      Mode deep sleep membuat chip ESP32 hanya memakai arus orde mikroampere, lalu bangun tiap beberapa menit untuk mengirim data.

      Aturan penting kalau kamu pindah dari Arduino

      • 3.3VLogika ESP32 adalah 3.3 V. Jangan beri 5 V langsung ke GPIO. Sinyal dari sensor 5 V perlu pembagi tegangan atau level shifter.
      • ADC2Saat WiFi aktif, pin ADC2 (GPIO 0, 2, 4, 12–15, 25–27) tidak bisa analogRead. Pakai ADC1: GPIO 32–39.
      • 34–39GPIO 34, 35, 36 (VP), dan 39 (VN) hanya bisa input dan tidak punya pull-up internal.
      • 0-4095analogRead menghasilkan 0–4095 (12-bit), bukan 0–1023. Serial Monitor biasanya diset 115200 baud.
      • BOOTPin strapping (GPIO 0, 2, 5, 12, 15) menentukan mode saat menyala. Jangan beri beban yang menarik pin ini ke level yang salah.
      • 6–11GPIO 6–11 dipakai memori flash dan tidak dikeluarkan di board 30 pin. Kalau ada di board lain, jangan dipakai.
      • 20mAArus tiap pin sebaiknya di bawah 20 mA. Motor, relay, dan lampu selalu lewat modul driver, bukan langsung dari pin.
      • GNDKalau memakai catu daya terpisah (baterai motor, adaptor), sambungkan GND-nya ke GND ESP32.
      Cara kerja

      Apa yang sebenarnya terjadi di dalam

      Tiga konsep yang paling sering dipakai di project ESP32. Pilih topik, lalu mainkan kontrol di samping.

      ESP32 bisa pakai WiFi

      Seperti HP, ESP32 punya WiFi di dalamnya. Antenanya garis zig-zag emas di ujung board. Ada dua cara memakainya, pilih salah satu:

        
          
        ESP32 cuma bisa pakai WiFi 2.4 GHz. Kalau WiFi rumahmu punya dua nama, misalnya RumahKu dan RumahKu_5G, pilih yang tanpa 5G.
        
        
        
        
        
          
        ADC mengubah tegangan jadi angka
        
          
        Potensiometer membagi tegangan 3.3 V. ADC 12-bit mengukur tegangan di pin D34 dan mengubahnya jadi angka 0–4095. Dua belas kotak di atas adalah 12 bit angka itu.
        
          
        
          
          
        
            
        1.65 VTegangan pin
        
            
        2048analogRead(34)
        
          
        
          
        100000000000Dalam biner (12 bit)
        
          
        // angka mentah 0–4095
int nilai = analogRead(34);
// perkiraan tegangan
float volt = nilai * 3.3 / 4095.0;
// lebih akurat, dalam milivolt
int mv = analogReadMilliVolts(34);
        
          
        ADC ESP32 kurang linear di dekat 0 V dan 3.3 V. Untuk nilai tegangan, analogReadMilliVolts() memakai kalibrasi pabrik sehingga lebih akurat.
        
        
        
        
        
          
        PWM: pura-pura analog
        
          
        Kebanyakan pin ESP32 hanya bisa HIGH (3.3 V) atau LOW (0 V). PWM menyalakan dan mematikan pin sangat cepat. Persentase waktu HIGH disebut duty cycle, dan rata-ratanya terasa seperti tegangan lebih rendah.
        
          
        
          
          
        
            
        77ledcWrite (0–255)
        
            
        0.99 VTegangan rata-rata
        
          
        
          
        // pin 18, 5 kHz, resolusi 8-bit
ledcAttach(18, 5000, 8);
// 77 dari 255 = duty 30%
ledcWrite(18, 77);
        
          
        Matikan mode lambat. Pada 5 kHz mata tidak bisa melihat kedipan, jadi LED terlihat redup dan stabil. Cara yang sama dipakai untuk mengatur kecepatan motor.

            1. Install Arduino IDE 2
              Unduh dari arduino.cc. Kalau sudah punya, lanjut ke langkah berikutnya.
              2. 
          
            2. Tambahkan alamat board ESP32
              File → Preferences → Additional boards manager URLs, tempel alamat ini:
              
            
              https://espressif.github.io/arduino-esp32/package_esp32_index.json
              3. 
          
            3. Install paket board
              Tools → Board → Boards Manager, cari esp32, install esp32 by Espressif Systems (versi 3.x).
              4. 
          
            4. Colok board
              Pakai kabel USB data, bukan kabel charge saja. Kalau port tidak muncul, install driver CP210x atau CH340 sesuai chip USB di board kamu.
              5. 
          
            5. Pilih board dan port
              Tools → Board → ESP32 Dev Module, lalu Tools → Port. Kalau upload sering gagal, turunkan Upload Speed ke 115200.
              6. 
          
            6. Upload
              Kalau muncul Connecting..... terus-menerus, tahan tombol BOOT di board sampai persentase upload mulai berjalan.
